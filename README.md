## Local preview

Because this site is static HTML, you can preview quickly with any local web server from the repository root.

Example:

```bash
python3 -m http.server 4000
```

Then open `http://localhost:4000`.

## Deployment

The repository is deployed through GitHub Pages. Pushing changes to the repository triggers the Pages build and deployment workflow.
