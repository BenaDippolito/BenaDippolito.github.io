## How this page will be updated

When the Word document is provided, transfer notes into the existing placeholders section by section:

1. Keep the current heading structure.
2. Replace `[Placeholder]` prompts with source-based notes.
3. Do not add verbatim copyrighted ISO standard text.
4. Keep notes factual and traceable to the source material.
